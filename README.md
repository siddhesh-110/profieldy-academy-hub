# ProFieldy: Academy Hub

Create a premium modern landing page for a Sports Academy Management System SaaS platform. Design style should be similar to high-end startup websites like Spyn Pro, with a clean light theme, smooth animations, elegant spacing, premium typography, and professional business feel.

Brand Name: ProFieldy

Target Audience:

- Sports Academy Owners

- Coaches

- Students / Players

Goal:

Convince sports academies to use the platform for managing their entire academy digitally.

Overall Style:

- Light premium modern UI

- White background with soft gradients

- Blue + Indigo + Black accent colors

- Glass-morphism cards where needed

- Clean shadows

- Rounded corners

- Smooth scroll animations

- Hover animations on buttons, cards, navbar links (darken, scale, glow, slide)

- Premium startup SaaS look

- Mobile responsive

1. Sticky Navbar
